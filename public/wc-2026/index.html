how grading works
  • Group stage: one point per group where my picked 1st-place team is the actual group winner. 2nd and 3rd are shown for context but only 1st is scored.
  • Knockout rounds: one point per match where my picked winner actually advances. Scored independently per round, so a wrong R32 pick doesn't cascade.
  • Champion: the team I expect to lift the cup. Worth a bonus brag if it lands.
  • "Graded": means a result has been entered for that match. "0/N graded" means no results yet for that round.

Live results come from football-data.org via a Cloudflare Worker at /api/wc-results. The Worker fetches the WC competition feed, derives group standings from finished matches (3 pts for a win, 1 for a draw, goal diff tiebreaker), and caches the response in Workers KV for 1 hour. The browser additionally caches the result in localStorage for 30 minutes. If the upstream API is down, the Worker serves stale KV data; if that's also unavailable, the client falls back to the static data/wc-2026-results.json. The bracket tree highlights my champion's path in green; correct picks turn the card border green, wrong picks orange.
