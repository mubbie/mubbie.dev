how scoring works

Quick version: I get a point every time my pick matches reality.

  • Group stage: a point for each group where my picked winner is the actual group winner. 2nd and 3rd are shown for context but don't score.
  • Knockout rounds: a point for each match I picked the winner of. Each round is scored on its own, so missing one R32 game doesn't snowball.
  • Champion: the trophy is the big one. If France lifts it, I get bragging rights for four years.
  • The bracket tree highlights France's path in green. Correct picks turn the card border green, wrong picks orange. Easy to see at a glance how much my bracket survives.

Results come straight from football-data.org. The site holds onto them for a bit so the page loads fast. Hit the refresh button next to the indicator above any time you want the very latest. If something's wrong on their end, the page shows the last good fetch instead, so it never breaks. The indicator above tells you which one you're looking at.
